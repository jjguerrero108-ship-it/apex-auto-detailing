# Apex Auto Detailing

A responsive React website for the fictional Apex Auto Detailing business. It uses Vite for local development and production builds.

## Requirements

- Node.js 18 or newer
- npm (included with Node.js)

## Install and run

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`). To create and preview a production build, run:

```sh
npm run build
npm run preview
```

The contact form creates an email draft addressed to the example placeholder `hello@example.com`; replace the placeholder contact details before using the site for a real business.

## Project files

- `src/main.jsx` — React components and page content
- `src/styles.css` — responsive layout, colors, typography, and interaction styles
- `index.html` — document metadata and font loading
- `package.json` — npm dependencies and scripts

Automotive photos are referenced from Unsplash image URLs in `src/main.jsx`, and the fonts are loaded from Google Fonts in `index.html`. Those visual assets require an internet connection and are not stored as local files in this project.
